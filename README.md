# Tap The Black Tiles

## Overview

Tap The Black Tiles is an interactive browser-based clicker game developed using HTML, CSS, and JavaScript.

The objective of the game is to click the black tiles as quickly as possible before the time runs out. The game includes dynamic scoring, a high-score system, countdown animation, and real-time visual feedback to create an engaging user experience.

---

## Features

- Interactive tile clicking gameplay
- Dynamic score calculation
- High-score tracking using browser local storage
- Countdown before starting the game
- Real-time timer system
- Dynamic point system based on reaction speed
- Visual feedback for correct and incorrect clicks
- Confetti animation for achieving a new high score

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage API

---

## Game Mechanics

- The player has a limited amount of time to score points.
- Black tiles appear randomly on the board.
- Clicking a black tile increases the score.
- Faster reactions provide higher points.
- The highest score is saved locally in the browser.
